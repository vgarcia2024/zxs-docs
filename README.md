# 💬 ZXS-DOC — Chat y datos de clientes de Zeroxsiento

Aplicación web de **Zeroxsiento (PagoFácil)** para comunicarse con los clientes por chat y para que ellos puedan **guardar su información** de forma simple y ordenada.

🔗 App en producción: [zxs-doc.vercel.app](https://zxs-doc.vercel.app)

---

## 📌 ¿Para qué sirve?

- Los clientes cargan y guardan su información personal/de trámite desde cualquier dispositivo.
- El equipo de Zeroxsiento se comunica con cada cliente mediante un chat integrado.
- Toda la información queda centralizada, sin depender de papeles ni de mensajes sueltos.

## ✨ Funcionalidades

- **Chat con clientes:** conversación directa entre el cliente y el equipo.
- **Datos del cliente:** formulario para que cada cliente guarde y consulte su información.
- **Acceso desde el celular:** pensada para usarse cómodamente desde cualquier dispositivo.
- **Panel interno:** vista del equipo para gestionar clientes y conversaciones.

## 🚀 Uso

1. Ingresá a [zxs-doc.vercel.app](https://zxs-doc.vercel.app).
2. Completá tus datos para que queden guardados.
3. Usá el chat para comunicarte con el equipo de Zeroxsiento.

## 🔒 Privacidad

Los datos de los clientes se usan únicamente para la gestión de los servicios de Zeroxsiento.
